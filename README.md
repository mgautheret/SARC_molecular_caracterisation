# Molecular caracterisation of the sarcomatoid (SARC) bladder cancer variant 

## Context 
These scripts were used to perform transcriptomic and genomic profiling of the sarcomatoid bladder cancer variant. This project is conducted by the IMPACT team at Institut Curie (Paris, France). More specifically, these scripts analyze 3'RNA-seq and WES (Whole Exome Sequencing) data.
Note (2026-08-17): The WES analysis pipeline is not yet available on GitHub and is still under development.
